2. **产物落点**：生成的文件一律写入当前工作目录（或用户在本次请求中明确指定的位置），文件名遵循本技能的命名约定；禁止把产物写到工作区根目录之外或临时目录。
3. **数据边界**：只读取本技能流程声明需要的数据源（如 todo_read / 用户消息），禁止为"丰富内容"而虚构未发生的工作、编造数据或引用不存在的文件。

# 采购清单技能

## 目标
产出一份分类清晰、去重合并、可直接执行的购物清单。

## 工作流程

### 第一步：提取物品
从用户消息中提取所有物品需求，标准化：
- 物品名 + 数量 + 规格（如"牛奶 2L × 2盒"）
- 合并重复项（"买牛奶" + "再买两盒奶" → 牛奶 2L × 2盒）

### 第二步：分类整理

```markdown
# 采购清单 — {日期}

## 🥬 食品生鲜
| [必买] | 物品 | 数量 | 备注 |
|--------|------|------|------|
| ✅ | 牛奶 2L | 2 盒 | 低脂 |
| ✅ | 鸡蛋 | 30 枚 | |
| ⬜ | 三文鱼 | 1 块 | [可选] 周末做饭用 |

## 🧴 日用品
| [必买] | 物品 | 数量 | 备注 |
|--------|------|------|------|
| ✅ | 洗衣液 | 1 瓶 | 补货 |

## 💻 数码
...

## 💰 预算估算
- 必买小计：约 ¥{X}
- 全部（含可选）：约 ¥{Y}
```

### 第三步：建入待办（需用户确认）
"是否需要把必买项建为今日待办？"

用户同意后：
```
todo_create(text="#采购 {物品列表摘要} 预算约{金额}")
```

### 第四步：可选导出
- `create_spreadsheet(path="采购清单_{日期}.xlsx", rows=清单数据)` → Excel（首行自动表头：加粗+深蓝底+冻结+筛选；需要预算小计时加 `sum_row: true` 生成合计行）
- 直接在对话中展示（默认）

## 质量标准
- 分类清晰，同类物品相邻
- 去重彻底（同一物品不同说法合并为一条）
- 数量与规格明确（"一些"→ 问用户具体多少）
- 预算标注区分必买/可选

## 失败处理与红线
- create_spreadsheet 报错 → 把失败原因原样告知用户，同时在对话中展示 Markdown 表格版清单（保证信息不丢）
- 用户没给数量 → 标注「数量待确认」而非猜一个数
- **红线**：预算估算区分「必买」与「含可选」；去重彻底
