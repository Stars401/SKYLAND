## 执行纪律（强制 — 违反任意一条即视为未完成本技能）

1. **严格按本技能的工作流程逐步执行**，不得跳步、不得省略中间产出；流程中声明的每一步都必须有对应的实际动作或输出。
2. **产物落点**：生成的文件一律写入当前工作目录（或用户在本次请求中明确指定的位置），文件名遵循本技能的命名约定；禁止把产物写到工作区根目录之外或临时目录。
3. **数据边界**：只读取本技能流程声明需要的数据源（如 todo_read / 用户消息），禁止为"丰富内容"而虚构未发生的工作、编造数据或引用不存在的文件。
4. **冲突上报**：若用户请求与本技能流程冲突（如要求跳过数据拉取、伪造日期），先说明冲突点并征求确认，未经确认不得擅自偏离。
5. **完成汇报**：结束时必须逐项核对产出物清单，按「做了什么 → 产物在哪 → 遗留/下一步建议」三段式汇报，不得只回一句"已完成"。

# 晨间简报技能

## 目标
让用户在 30 秒内掌握今天该干什么。

## 工作流程

### 第一步：拉取今日待办
```
调用 todo_read(scope="today")
```
提取：高优先项（!! 标注）、今日总数、已完成数。

### 第二步：拉取逾期项
从 `todo_read` 返回的 carryover 数据中提取跨天未完成项。

### 第三步：获取外部资讯（可选）
```
调用 web_search(query="今日科技新闻头条")
```
- 搜索可用：取 1 条行业新闻 + 1 条天气（按用户所在城市）
- 不可用：跳过，不占版面

### 第四步：生成简报

输出结构（对话中直接展示 Markdown）：

```markdown
## 📅 {日期} {星期} 晨间简报

> 一句开工寄语

### 今日待办（{n} 项 · 已完成 {m}）
- 🔴 [高优先] 事项 A
- 🔴 [高优先] 事项 B
- ⚪ 常规事项 C、D、E

### ⚠️ 逾期提醒（{k} 项）
- 「事项 X」已逾期 {n} 天 → 建议：继续/放弃/改期

### 🌤️ 外部资讯
- {新闻标题}（一句话摘要）
- {天气提示}
```

### 第五步：可选保存
若用户希望留档：
- `create_document(path="晨间简报_{日期}.docx", title="晨间简报 {日期}", content=上述Markdown)` → Word 文件
- 或直接在对话中展示即可（默认）

## 质量标准
- 总长不超过 15 行正文
- 高优先项必须逐条列出，不折叠
- 逾期项必须给出明确建议（不是罗列完事）

## 失败处理与红线
- `todo_read` 报错或返回空 → 直接告知用户「今日待办暂无数据」，跳过待办与逾期版块，只输出寄语与资讯；**绝不编造待办事项**
- `web_search` 不可用 → 跳过外部资讯版块，不要留空标题
- 天气搜索无结果 → 提示用户自行查看，不要猜温度
- **红线**：全部步骤完成后必须输出完整简报文本回复（禁止只调工具不说话）；简报中的数字必须来自工具返回值
