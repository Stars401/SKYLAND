# 晨间简报技能

## 目标
让用户在 30 秒内掌握今天该干什么。

## 工作流程

### 第一步：拉取今日待办
```
调用 todo_read(scope="today")
```
提取：高优先项（!! 标注）、今日总数、已完成数。

### 第二步：拉取逾期项
从 `todo_read` 返回的 carryover 数据中提取跨天未完成项。

### 第三步：获取外部资讯（可选）
```
调用 web_search(query="今日科技新闻头条")
```
- 搜索可用：取 1 条行业新闻 + 1 条天气（按用户所在城市）
- 不可用：跳过，不占版面

### 第四步：生成简报

输出结构（对话中直接展示 Markdown）：

```markdown
## 📅 {日期} {星期} 晨间简报

> 一句开工寄语

### 今日待办（{n} 项 · 已完成 {m}）
- 🔴 [高优先] 事项 A
- 🔴 [高优先] 事项 B
- ⚪ 常规事项 C、D、E

### ⚠️ 逾期提醒（{k} 项）
- 「事项 X」已逾期 {n} 天 → 建议：继续/放弃/改期

### 🌤️ 外部资讯
- {新闻标题}（一句话摘要）
- {天气提示}
```

### 第五步：可选保存
若用户希望留档：
- `create_document(path="晨间简报_{日期}.docx", content=上述Markdown)` → Word 文件
- 或直接在对话中展示即可（默认）

## 质量标准
- 总长不超过 15 行正文
- 高优先项必须逐条列出，不折叠
- 逾期项必须给出明确建议（不是罗列完事）
