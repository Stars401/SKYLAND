# 学习笔记技能

## 目标
把任意学习材料转化为"概念清晰 + 结构可视 + 可自测 + 有复习计划"的笔记。

## 工作流程

### 第一步：获取材料
- 用户直接粘贴文本 → 直接进入第二步
- 用户给知识库文档 → `kb_search(query="...")` 定位后 `kb_read(kb="...", path="...")` 读取
- 用户给本地文件 → `read_file(path="...")` 读取

### 第二步：提取核心概念
- 识别 3-5 个最重要的概念/原理/方法
- 每个概念：一句话定义 + 一个具体例子
- 定义必须忠于原材料，不外加未经确认的知识

### 第三步：构建知识结构
- 用层级列表展示概念间的包含/并列/递进关系
- 类似思维导图但用文字表示

### 第四步：生成记忆卡
- 5-8 张 Q/A 卡，Q 在前 A 换行在后
- Q 应覆盖：定义（"X 是什么？"）、区别（"A 和 B 的区别？"）、应用（"什么时候用 X？"）
- A 控制在一句话内（可背诵的长度）

### 第五步：制定复习计划
基于艾宾浩斯遗忘曲线：

| 复习节点 | 时间 | 目标 |
|---------|------|------|
| 第 1 次 | 明天 | 回忆全部概念名 |
| 第 2 次 | 3 天后 | 做记忆卡自测 |
| 第 3 次 | 7 天后 | 用自己的话复述核心内容 |

### 第六步：输出笔记

```markdown
# 学习笔记 — {主题}

## 核心概念
1. **{概念 A}**：{一句话定义}
   > 例子：{具体例子}
2. ...

## 知识结构
- {大类}
  - {子类 1}：{一句话}
  - {子类 2}：{一句话}
- {另一大类}
  ...

## 记忆卡
Q1: {问题}
A1: {一句话答案}

Q2: {问题}
A2: {一句话答案}
...

## 复习计划
- [ ] 明天：回忆全部概念名
- [ ] 3 天后：记忆卡自测
- [ ] 7 天后：复述核心内容
```

### 第七步：建入待办（需用户确认）
"是否将复习计划建入待办系统？"

用户同意后：
```
todo_create(text="#学习 {主题} 复习第1次：回忆概念名 @{明天日期}")
todo_create(text="#学习 {主题} 复习第2次：记忆卡自测 @{3天后日期}")
todo_create(text="#学习 {主题} 复习第3次：复述核心内容 @{7天后日期}")
```

### 第八步：可选导出
- `create_document(path="学习笔记_{主题}.docx", content=笔记Markdown)` → Word
- 直接在对话中展示（默认）

## 质量标准
- 忠于原材料 — 不外加未经确认的知识
- 术语首次出现给出通俗解释
- 记忆卡答案控制在一句话内（可背诵的长度）
- 知识结构用层级缩进展示，不用嵌套 Markdown 链接
