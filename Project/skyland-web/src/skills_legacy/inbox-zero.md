# 待办清理顾问技能

## 目标
把积压的待办清理到"今日清单 ≤ 5 件事"的状态。

## 工作流程

### 第一步：拉取全部待办
```
调用 todo_read(scope="recent")
```
获取最近 7 天所有**未完成**事项。

### 第二步：四组分类

对每条未完成事项判断归属：

| 组 | 判断标准 | 处理方式 |
|---|---------|---------|
| ⚡ 2分钟可完成 | 简单回复/确认/转发 | 建议立即做掉（在对话中直接给出回复模板） |
| 🔧 需要拆分 | 超过半天工作量 / 描述模糊 | 拆分为 2-3 个具体子任务 |
| 🗑️ 已过时 | 依赖已消失 / 目标已变 | 建议放弃，说明理由 |
| 📅 应改期 | 有价值但今天不做 | 建议改到具体日期 |

### 第三步：输出清理报告

```markdown
# 待办清理报告

## 总览
- 积压：{n} 项未完成（跨 {d} 天）
- 目标：清零积压，今日清单聚焦 ≤ 5 件

## ⚡ 2 分钟可完成（{a} 项）— 建议现在做掉
1. 「{事项}」→ {具体操作建议}
2. ...

## 🔧 需要拆分（{b} 项）
| 原事项 | 拆分建议 |
|--------|---------|
| {大任务} | ① {子任务1} ② {子任务2} |

## 🗑️ 建议放弃（{c} 项）
- 「{事项}」：{放弃理由}

## 📅 建议改期（{d} 项）
| 事项 | 建议日期 |
|------|---------|
| {事项} | 改到 {具体日期}，理由：{...} |
```

### 第四步：批量执行（需用户逐条确认）
对每一组操作征求用户确认：
- **拆分**：确认后 `todo_create(text="#分类 {子任务}")` × N 条
- **放弃**：确认后告知用户自行在待办页面标记完成/删除（AI 不代做删除决定）
- **改期**：确认后 `todo_create(text="#分类 {事项} @{日期}")` 延续到新日期

## 质量标准
- 不替用户做删除决定 — 只给建议，操作权在用户
- 每条建议必须具体（"拆分为 A 和 B"而非"建议拆分"）
- 改期建议给出具体日期而非"改天"
