# 工作日报技能

## 目标
产出一份客观、量化、上司可 30 秒扫完的工作日报。

## 工作流程

### 第一步：拉取今日数据
```
调用 todo_read(scope="today")
```
提取：全部事项列表、完成/未完成状态、优先级、分类标签。

### 第二步：合并用户补充
若用户消息中提到了额外工作内容（会议、沟通、临时任务），合并进对应分类。

### 第三步：生成日报

```markdown
# 工作日报 — {日期}

## 今日完成（{n} 项）
- ✅ **{高优先事项}**：一句话说明产出（量化：改了几个文件/修了几个Bug/写了多少行）
- ✅ {常规事项 A}：一句话
- ✅ {常规事项 B}：一句话

## 进行中（{m} 项）
- 🔄 {事项}：当前进度 + 卡点 + 预计完成时间

## 明日计划（{k} 件）
1. {最重要的事}
2. {次重要}
3. {其他}

## 备注
- {需要上级知晓的风险/依赖/求助}
```

### 第四步：可选导出
- `create_document(path="工作日报_{日期}.docx", content=日报Markdown)` → Word 文件
- 直接在对话中展示（默认）

## 质量标准
- 能用数字就用数字（"修复 3 个 Bug" 而非 "修了一些 Bug"）
- 不虚构未提及的细节；信息不足先向用户确认
- 明日计划不超过 3 件，按优先排序
- 高优先完成项加粗，让扫读者第一眼看到
